# 本地使用

## 启动

在仓库根目录运行：

```bash
npm start
```

浏览器打开 `http://127.0.0.1:4317`。停止服务使用终端中的 `Ctrl+C`。

## 写作流程

1. 在书架点击“新建作品”，填写书名、立意、题材、风格、篇幅和每章字数。
2. 打开作品后，依次运行世界观、角色表、故事规划和卷大纲。每次生成都会写入作品目录，完成的阶段可以重复查看。
3. 进入“工作台”，填写本章指导和目标字数，运行成文。
4. 在正文编辑器中修改标题和正文，点击“保存修改”会创建一个历史版本；可以整章润色、恢复历史版本或运行后验定稿。
5. 通过作品页右上角下载 Markdown 或 TXT。导出的范围默认是全部已生成章节。

## 本地资料

每本书位于 `data/books/<slug>`，包括：

- `meta/`：世界观、角色和故事规划
- `world/`：世界状态原始资料
- `outline/`：卷纲和近期细纲
- `story/`：章节正文、版本和后验结果
- `archive/`：长期索引
- `cache/`：中间资料

复制整个书籍目录即可备份或迁移。书籍不依赖账号、数据库或云服务。

## 当前生成模式

当前版本使用确定性模拟生成器，便于无 API Key 的本地开发和流程验收。页面会显示“本地模拟模式”。它验证的是书籍存档、阶段约束、章节编辑和恢复流程，不代表真实模型的文风或质量。

DeterminFlow 和公开 `bishu-novel` 插件的接入边界已经记录在 `docs/LOCAL-BISHU-PLAN.md`；接入真实模型时可替换生成器而保留本地书籍格式。
